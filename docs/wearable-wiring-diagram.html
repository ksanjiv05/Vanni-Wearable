Wiring notes (learned the hard way)

  • INMP441 VDD = 3.3V only — it's a 3.3V part; 5V can damage it.
  • L/R → GND selects the LEFT channel. Left floating = silence/garbage.
  • microSD VCC = 5V on this module (regulated). If it won't mount, try the other rail.
  • TFT + SD share the HSPI bus (SCK 12, MOSI 11). MISO 13 is used by SD only — but you must pass MISO=13 to spiBus.begin or the TFT inits white.
  • Mic is on I²S (GPIO 4/5/6) — a separate peripheral, no conflict with the SPI bus.
  • A firmware SPI mutex guards SD vs TFT (they run on different cores).

What it does

  • Hands-free capture: say "Hi ESP" → records to /vaani/note_*.wav, auto-stops after ~2s of silence.
  • On-screen states: Listening → SPEAK NOW → RECORDING → SAVED, plus a glance dashboard (app-link, pending count, today's todos).
  • App-link: encrypted BLE (bonded, per-device secrets) is primary; Wi-Fi SoftAP on demand for faster bulk pull.
  • Sync: the phone auto-pulls notes on connect → transcribe → enrich → searchable notes.
  • Build: PartitionScheme=esp_sr_16 (ESP-SR needs the model partition).
